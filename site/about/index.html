About Unlimited Dailies

Unlimited Dailies is a small independent website that makes free, unlimited practice versions of popular daily puzzle styles. Our first game is Sumbreak Unlimited, a number-merge logic puzzle, together with a solver and a strategy guide.

All puzzles are created by our own generator, and every board is checked to be solvable. The site is free to use and is supported by advertising.

We are not affiliated with LinkedIn, Microsoft, The New York Times or any other game publisher. Game names are used only to describe the style of puzzle.
